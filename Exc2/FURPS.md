|-----|------------------------------------|--------------|
| F   | **Функциональные (Functionality)**     |              |
| F1  | Новые пользователи сайта и интернет-банка должны видеть список доступных депозитов с актуальными ставками                                |    пп1          |
| F2  | Клиент должен иметь возможность подать заявку на депозит, указав телефон и ФИО                                |  пп1            |
| F3  | Заявки на депозиты должны заноситься в систему и передаваться сотруднику кол-центра                                |  пп1            |
| F4  |В интернет-банке клиент должен видеть список доступных депозитов с персональными ставками лично для него                                |  пп2            |
| F5  | Клиент может подать заявку на открытие депозита, указав счет и сумму                                |  пп2            |
| F6  | Функционал согласования ставок необходимо перевести в АБС                                |  пп2            |
| F7  | Для клиента необходимо реализовать СМС-оповещение после согласованиия депозита и ставки                                |  пп4            |
| F8  | Сотрудник отделения может подать заявку напрямую в АБС, если клиент сразу придет в отделение, чтобы открыть депозит                                |  пп1            |
| U   | **Удобство использования (Usability)** |              |
| U1  | Интерфейс работы должен быть максимально удобным для клиента                                |  пп5            |
| U2  | Нужно придерживаться системы дизайна для приложений, которая принята в компании. Пользователи при работе должны видеть привычные цвета и брендированные элементы                                |  пп5            |
| R   | **Надёжность (Reliability)**           |              |
| R1  | Передача данных с сайта должны производиться по защищенному протоколу с шифрованием трафика                               |  пп1            |
| R2  | Подтверждения операций должны производиться с помощью СМС-кода                                 |  пп2            |
| R3  | Протокол общения АБС - интернет-банк должен быть защищен механизмом шифрования                                 |  пп2            |
| R4  | все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                 |  пп6            |
| R5  | Необходимо предусмотреть резервирование систем банка в другом ЦОД                                 |  пп6            |
| R6  | Надо предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД                                 |  пп6            |
| P   | **Производительность (Performance)**   |              |
| P1  | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                                |  пп5            |
| P2  | Необходимо по-возможности снизить нагрузку на БД                                |  пп6            |
| S   | Поддерживаемость (Supportability)  |              |
| S1  | нужно предусмотреть разработку документации для дальнейшего расширения системы                                |  пп3            |
| S2  | Необходимо использовать привычные для сотрудников технологии, например, MS SQL и Oracle. Новые технологии должны быть совместимы                                |  пп3            |
| +R  | **+ Ограничения (Restricitions)**      |              |
| R1  | Банки не принимают новых клиентов без личной проверки документов                                |  пп1            |
| R2  | Функционал СМС-оповещений требует доработок партнеров, лучше этого избежать                                |  пп2            |
| R3  | Ставки по депозитам ведутся только в XLS, с ними работают сотрудники бэк офиса, до перехода на АБС эту процедуру надо сохранить                                |  пп2            |
| R4  | Для очередей сообщений необходимо использовать Kafka                               |  пп3            |
| R5  | Лучше избежать прямой работы интернет-банка с API АБС в новом процессе                               |  пп6            |
| R6  | АБС может масштабироваться только вертикально из-за своей базы данных                               |  пп6            |
| R6  | Использовать платформы и субд Java, .NET, PHP, MS SQL, Oracle                                |  пп3            |
